# 3D Lighting & Materials

## 1. 职责与边界

将已批准的场景和镜头方案转化为可执行的灯光、材质和表面细节方案。目标是让产品真实、结构清晰、质感可信，同时保持跨镜头一致。

- 主 Skill 负责科学事实、脚本和整体视觉方向。
- 场景 Skill 负责空间、对象和道具布局。
- 镜头 Skill 负责摄影机、构图和运镜。
- 本 Skill 负责灯光、材质、纹理、反射、曝光和渲染一致性。
- 不擅自改变产品真实材料、颜色或结构；不把视觉效果伪装成科学现象。

## 2. 灯光设计工作流

### Step 1 — 明确视觉目的
每组灯光必须服务于一个目的：建立环境、塑造轮廓、展示材质、突出关键部件、分离前后景或解释过程。先确定观众应该看清什么，再决定灯光。

### Step 2 — 建立基础布光
按场景选择，不强制每个场景都使用三点布光：
- **Key light 主光**：决定主体主要明暗关系和方向。
- **Fill light 补光**：控制暗部细节，避免重要结构沉入黑色。
- **Rim / Back light 轮廓光**：帮助主体从背景分离，尤其适用于深色产品。
- **Practical / Environment light 环境光**：让光线看起来来自真实空间中的窗户、灯具或屏幕。
- **Bounce light 反弹光**：为暗部提供自然环境色，不要无理由地给所有表面染色。

记录每盏灯的类型、位置/方向、尺寸、强度关系、色温/颜色、阴影软硬和作用对象。不要只写“电影级布光”。

### Step 3 — 材质基准
每种材质至少明确：
- Base Color / 基础颜色
- Metallic / 金属度
- Roughness / 粗糙度
- IOR / 折射率（适用时）
- Transmission / 透射（适用时）
- Coat / Clearcoat（适用时）
- Normal / Bump / Displacement（需要表面细节时）
- 纹理尺度、方向和重复规律

参数是起点而非物理测量值。若材料属性未知，标记为艺术化近似，不要声称是精确材质参数。

### Step 4 — 材质与灯光共同检查
- 高光不能吞掉按钮、接口、刻字或关键结构。
- 黑色塑料仍需保留边缘和形体信息，不能变成无细节黑块。
- 白色/浅色产品避免过曝失去轮廓。
- 金属反射要有环境依据，避免镜面反射让主体不可读。
- 玻璃和透明塑料需检查厚度、折射、反射及背景对比；关键内部结构不能被反射遮住。
- 半透明外壳只用于说明目的，必要时标注“结构示意”。
- 粗糙度、颜色和反射随镜头保持稳定，不可每个镜头随意变化。

### Step 5 — 科学视觉边界
- 不用红蓝光暗示真实温度、气流或电流，除非画面建立了明确图例。
- 光束、辉光、粒子、体积雾均是视觉表达，不自动代表真实物理实体。
- 不能靠不真实的材质透明度让观众误判产品实际结构。
- 对真实产品外观，优先参考用户提供的照片、官方图片或已核验资料。

## 3. Blender 执行规范

建议先建立可复用的灯光 Rig，再针对场景微调：
- 用命名清晰的 Area / Point / Spot / Sun 等灯光对象。
- 按职责放入 `LIGHT_KEY`、`LIGHT_FILL`、`LIGHT_RIM`、`LIGHT_ENV` 等 Collections。
- 统一色彩管理与 View Transform；整个项目记录曝光、Look 和白平衡基准。
- 材质使用可复用 Node Group 或命名材质库，避免同一产品各镜头材质漂移。
- 纹理使用真实尺度；避免明显拉伸、重复接缝和不合理磨损。
- 先用低采样/低分辨率做灯光灰模和材质预览，再进行最终渲染。
- 记录渲染引擎、分辨率、采样、降噪、色彩管理和输出格式，保证可复现。

## 4. 输出格式

每个场景或镜头输出：
1. 灯光意图与参考氛围
2. 灯光清单：类型、位置/方向、强度关系、色温、尺寸、阴影、作用对象
3. 材质清单：对象、材质类型、颜色、粗糙度/金属度/透射等关键属性、纹理尺度
4. 关键反射和高光控制
5. Blender 对象/Collection/材质命名
6. 预览渲染设置与最终渲染建议
7. 与前后镜头的光照/材质连续性约束
8. 验收清单

## 5. 中文与趣味规范

灯光、材质是视觉制作内容，不得擅自把画面内技术标签改成英文。面向观众的标签、图注和字幕使用简体中文；旁白和对白使用自然普通话中文，语气轻松、有故事感、适度幽默但科学准确。模型不能可靠生成汉字时，留白并在后期添加校对后的中文。

## 6. 验收清单

- [ ] 主体轮廓清楚，第一视觉焦点明确
- [ ] 关键部件没有过曝、死黑或被反射遮挡
- [ ] 材质外观符合参考资料或明确标记为艺术化近似
- [ ] 玻璃/透明材质没有掩盖结构或制造错误印象
- [ ] 光线方向和色温符合场景逻辑
- [ ] 同一产品跨镜头颜色、粗糙度和反射表现一致
- [ ] 色彩管理、曝光和渲染设置有记录
- [ ] 视觉化光效没有冒充真实物理现象
- [ ] 中文字幕/标签区域可读，画面文字无乱码
