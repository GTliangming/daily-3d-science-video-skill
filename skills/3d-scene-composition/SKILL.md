# 3D Scene Composition Skill

## 1. 职责

把已确认的分镜转化为可搭建、可拍摄、可复用的 3D 场景方案。重点不是堆砌装饰，而是让观众在每个镜头里迅速看懂主体、动作和科学信息。

本 Skill 是主 Skill 与 3D 镜头 Skill 的下游模块：
- 主 Skill 负责选题、科学核验、脚本与分镜批准。
- `3d-camera-cinematography` 负责镜头语言、摄影机和运镜。
- 本 Skill 负责场景空间、对象布局、环境、道具、层次和场景连续性。

不得绕过科学核验；不得自行编造产品内部结构。

## 2. 场景设计顺序

对每个场景依次确定：

1. **场景目的**：建立环境、解释结构、展示因果、对比状态、情绪过场或收束。
2. **主体清单**：主产品/人物、关键部件、辅助物体、背景物体；标记必须准确与可艺术化的对象。
3. **空间布局**：明确坐标/方位关系、主体朝向、相机可见面、动作空间和遮挡关系。
4. **三层构图**：
   - 前景：提供空间纵深，不得遮挡关键动作或字幕。
   - 中景：承载主要叙事主体和关键动作。
   - 背景：交代环境与氛围，控制细节密度。
5. **视觉层级**：第一视觉焦点必须是当前镜头最重要的信息；辅助元素降低对比度、亮度或细节。
6. **光线与材质**：先保证形体可读，再塑造氛围；同一物体跨镜头保持材质参数和颜色一致。
7. **镜头适配**：检查景别、透视、景深、画幅和运动路径是否与摄影设计冲突。
8. **连续性**：记录物体位置、朝向、开关状态、部件状态、光照方向和环境状态。

## 3. 场景布局规则

- 采用明确的主体占比和视觉焦点，不要让背景抢戏。
- 关键结构应有无遮挡的展示角度；需要时拆成独立镜头，而不是强行塞进一个画面。
- 竖屏 9:16 必须原生设计：主体优先沿纵向组织，避免把关键部件放在左右边缘；预留字幕安全区。
- 需要解释内部结构时，使用经核验的剖切、爆炸、局部放大或独立示意空间；标注“结构示意”或“原理示意”。
- 不要把装饰性粒子、光效、烟雾或光束伪装成真实物理现象。
- 场景中出现人物时，明确人物视线、站位、动作目标和彼此关系；次要人物用于建立真实生活情境，不要无目的地围观或重复动作。
- 真实产品外观镜头与内部结构示意镜头可采用不同空间，但必须通过色彩、材质、方向或图形语言建立关联。

## 4. Blender 场景组织

建议按场景和职责组织 Collections：
- `ENV_*`：环境、地面、墙体、布景。
- `HERO_*`：主产品或主角。
- `PART_*`：经过核验的产品部件。
- `PROP_*`：辅助道具。
- `LIGHT_*`：灯光。
- `CAM_*`：摄像机和 Rig。
- `FX_*`：仅用于明确标注的视觉化效果。
- `GUIDE_*`：构图辅助线、标尺、注释；最终渲染按需隐藏。

命名使用稳定、可读的英文对象 ID；面向观众的画面文字、字幕和语音仍遵守项目中文规范。对象原点、单位尺度、父子关系和动画控制器应保持一致。不要把整个场景做成无法单独调整的单一网格。

## 5. 场景交付格式

每个场景输出：
- Scene ID / 名称 / 叙事目的
- 画幅与预计镜头
- 空间布局（文字说明；必要时提供俯视布局 ASCII 示意）
- 主体、部件、道具清单
- 前景/中景/背景
- 主体坐标、朝向和动作空间
- 灯光与材质基准
- 镜头可见区域与遮挡检查
- 连续性状态表
- Blender Collections 与对象命名
- AI 视频可用部分及不可交给 AI 自由发挥的部分
- 验收清单

## 6. AI 场景提示词原则

AI 提示词应明确：空间类型、主体位置、环境布局、道具数量与位置、光线方向、镜头可见面、画幅和不可变化项。不要仅写“高级、漂亮、电影感”。

若画面涉及精确部件数量、内部构造、物理过程或产品品牌外观，优先 Blender/参考图约束，不依赖模型自由生成。

## 7. 中文内容与趣味表达

所有面向观众的可读文字和语言内容统一使用简体中文，除非用户明确指定其他语言：
- 旁白、人物对白、字幕、标题、画面标签、图注、信息图、片尾文字均为中文。
- 禁止随机英文、伪文字、乱码、无意义数字或模型臆造的品牌标识。
- 产品真实品牌/型号若必须出现，按用户提供或已核实资料准确呈现；否则使用中文通用名称。
- Blender 内部对象名、文件名、技术参数和制作说明可使用英文，不属于观众画面内容。

语气采用“有趣但可信”的中文科普表达：
- 旁白像一个懂行、会讲故事的人在解释，不像说明书或论文朗读。
- 可以用生活化类比、轻微反差、设问和恰到好处的幽默；每个笑点服务于知识理解。
- 不使用低幼卖萌、尬梗、夸张吓唬、网络热梗堆砌或不准确拟人。
- 科学结论、数字、风险和因果关系必须严谨；趣味性不能改变事实。
- 默认第三人称中文旁白为主线。画面人物可有自然交流；若没有明确要求，不让角色对白覆盖旁白主线。

## 8. 验收

- [ ] 主体和关键动作一眼可辨
- [ ] 前中后景层次清晰且不遮挡信息
- [ ] 空间关系与摄影机运动可执行
- [ ] 画幅适配，竖屏构图不是横屏简单裁切
- [ ] 关键结构与科学过程准确或明确标注为示意
- [ ] 跨镜头物体位置、外观、状态和光线连续
- [ ] 画面内所有可读文字为正确中文
- [ ] 旁白/对白为自然中文，语气有趣但不油腻
- [ ] AI 不擅自生成英文字幕、乱码、Logo 或无关文字
