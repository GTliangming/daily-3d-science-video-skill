# Scene layout patterns

## 1. Product hero scene
- 主体位于画面视觉中心或偏下的黄金区域，完整轮廓优先。
- 背景保持低信息密度，使用柔和渐变、真实空间或轻量布景。
- 用轮廓光分离主体与背景；高反射材质必须检查高光是否吞掉结构细节。
- 适用于产品外观、开场建立和章节转场。

## 2. Exploded-view / cutaway scene
- 只拆解有可靠依据的部件。
- 爆炸方向尽量沿产品主轴，部件间距足以辨认但不能暗示错误装配关系。
- 通过编号、引导线或中文标签建立对应关系；画面标签后期合成更可靠。
- 明确标注“结构示意”，不把示意布局冒充真实比例或真实装配状态。

## 3. Physical-process scene
- 先定义真实过程，再选择可视化编码。
- 气流、热量、水流、电流等视觉符号必须有图例或中文说明。
- 颜色、粒子、线条只表达约定含义，不应让观众误以为它们是肉眼可见实体。
- 重要因果关系应通过前后状态或局部特写展示。

## 4. Human-use scene
- 人物动作要有明确目的，手与产品的接触关系合理。
- 次要人物承担提问、观察或反应等功能，不做无意义背景表演。
- 人物嘴型与对白若不可靠，优先采用旁白，不要让模型生成错误口型或随机外语。
- 生活场景保持真实尺度、合理道具和自然站位。

## 5. Vertical 9:16 composition
- 主体沿画面纵向组织，重要细节集中在中央安全区域。
- 顶部留标题空间，底部留字幕空间；避免主体脸部、出风口、关键部件落在字幕区。
- 横向运动应控制幅度，避免主体出框。
- 每个镜头单独检查手机尺寸下的可读性。
