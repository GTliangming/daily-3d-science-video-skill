# 3D Asset Sourcing & Inspection Reference

## 1. 资源来源的角色

以下是可调查的来源，不代表每个条目都适合当前项目，也不代表平台上的所有资产采用同一许可。

| 来源 | 常见用途 | 使用前检查 |
|---|---|---|
| [Sketchfab](https://sketchfab.com/) | 产品、设备、道具、扫描模型 | 单个模型许可、作者署名、商业使用、下载权限、网格质量 |
| [BlenderKit](https://www.blenderkit.com/) | Blender 模型、材质、场景资产 | 资产等级/许可、是否需订阅、修改与商用范围 |
| [Poly Haven](https://polyhaven.com/) | HDRI、纹理、环境模型 | 单项资源页面、分辨率、来源与许可说明 |
| [ambientCG](https://ambientcg.com/) | PBR 材质、纹理、HDRI | 资源页许可、贴图类型、分辨率 |
| [CGTrader](https://www.cgtrader.com/) | 商业模型与定制资产 | 具体商品许可、用途限制、是否包含源文件 |
| [TurboSquid](https://www.turbosquid.com/) | 商业模型 | 具体授权条款、渲染/再分发限制 |
| 制造商/用户提供 | 指定产品外观、尺寸和结构依据 | 型号、资料版本、是否有权使用其图片/模型 |

## 2. 搜索策略

不要只搜产品名称。组合使用：
- 产品名称 + 3D model
- 产品名称 + CAD / STEP / STL
- 产品名称 + exploded view / teardown
- 产品名称 + internal components
- 具体部件名称 + 3D model
- generic household appliance + product render（只用于非关键通用道具）

下载前先检查预览图、模型截图、文件格式、面数/贴图、作者、许可和更新时间。对科学关键资产，不可用“外观差不多”的模型替代真实结构。

## 3. 下载模型的首轮检查

导入 Blender 后，先不要立刻放入正式场景：
1. 保存到 source 目录，不覆盖原文件。
2. 在独立检查文件中导入。
3. 检查尺寸、朝向、原点、层级和对象数量。
4. 检查法线、非流形几何、重叠面、破面和材质丢失。
5. 检查贴图是否嵌入或路径是否有效。
6. 查看是否包含不需要的摄像机、灯光、隐藏对象和未知脚本。
7. 检查是否有绑定、驱动器、约束或动画。
8. 记录清理工作量，决定复用、改造或重建。

不要运行来源不明模型文件中附带的脚本。不要在主项目中直接打开或覆盖未知来源工程文件；先隔离检查。

## 4. 格式选择

| 格式 | 优点 | 常见限制 | 推荐用途 |
|---|---|---|---|
| BLEND | 保留 Blender 数据块、节点、层级和动画 | 版本兼容与外部路径依赖 | Blender 内部主工程 |
| GLB/GLTF | 便于交换网格、材质和部分动画 | 节点/材质/动画需检查 | 通用资产交换、预览 |
| FBX | 常用于网格、骨架、动画交换 | 轴向、单位、材质转换可能有差异 | 人物/骨骼动画与跨软件交换 |
| OBJ | 简单、广泛支持 | 不适合复杂节点材质、Rig 和动画 | 静态几何 |
| STL | 几何交换简单 | 不保留常规材质/场景层级 | CAD/打印几何参考，不是最终电影资产首选 |
| STEP | CAD 精确实体与工程结构 | 需转换为可渲染网格，曲面细节与材质需重做 | 产品工程外形与尺寸参考 |

## 5. 建模取舍

- 画面里只出现 8 像素宽的螺丝，不必为它建立复杂螺纹。
- 产品轮廓在特写中清晰可见时，倒角、接缝、按钮和曲面质量很重要。
- 会独立旋转或拆开的零件必须分件，并正确设置原点。
- 只为展示外观的静态物体，可以适度合并网格。
- 需要剖切时，提前考虑切面材质、内部厚度和截面视觉表达。
- 需要爆炸图时，先定义装配状态和每个零件的回位位置。

## 6. 参考与许可档案

建议每个资产保存：
- 原始网页 URL 与访问/下载日期
- 作者和许可证
- 许可证页面副本或截图
- 下载文件原名与 SHA256（可选）
- 修改记录
- 署名要求
- 最终成片/项目的使用记录

许可判断不确定时暂停使用并咨询权利人；不要根据搜索结果摘要自行认定许可。
