# Animation patterns and timing

## 1. Product activation
1. Hold on the inactive product so its state is readable.
2. Show a clear trigger (button press, switch, plug-in) only if that control exists on the reference product.
3. Animate the response in causal order: control action, internal response, visible output.
4. Hold briefly on the stable operating state.
Do not show an instant unexplained transformation.

## 2. Rotating mechanism
- Confirm the real rotation axis and direction before animating.
- Parent the rotating component to a controller at the correct pivot.
- Keep housing and fixed components stationary.
- Use continuous rotation only while the operating condition is active.
- Avoid exposing a precise RPM unless a verified value is available.

## 3. Exploded view
- Define a fully assembled reference state.
- Move only verified parts along clear, non-intersecting paths.
- Stagger movement slightly so the viewer can follow the separation.
- Hold at the exploded state long enough to inspect.
- Reassemble in reverse order only if the storyboard needs it.
- Label as a structural visualization when spacing is not to scale.

## 4. Airflow visualization
- Establish the intake and outlet based on verified product geometry.
- Use restrained curves/particles to show direction, not as literal visible air.
- Keep paths continuous and prevent particles from passing through solid geometry.
- Use consistent color/line style and a Chinese legend in post-production.
- Avoid implying exact flow speed, pressure or temperature without data.

## 5. Heat transfer visualization
- Distinguish heat source, transfer path and receiving object.
- Do not depict heat as red liquid or glowing matter unless explicitly framed as a symbolic diagram.
- Use a labeled gradient or restrained animated field only as an explanatory convention.
- Avoid quantitative color scales without measured/sourced data.

## 6. Human interaction
- Block the hand path first, then animate fingers/grip and object response.
- Maintain contact at the grip point; check collision and scale.
- Use anticipation, action and a short settle rather than constant motion.
- Secondary characters should have distinct, motivated reactions; avoid synchronized crowd motion.

## 7. 8-second timing sketch
| Time | Beat |
|---|---|
| 0.0–1.0s | Establish initial state |
| 1.0–2.0s | Trigger / anticipation |
| 2.0–5.5s | Main action or causal reveal |
| 5.5–7.0s | Key information hold |
| 7.0–8.0s | Settle / transition pose |

This is only a timing example. Adapt to narration density and the shot's purpose. Keep every shot at or below 15 seconds.
