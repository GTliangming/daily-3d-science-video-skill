# 3D Animation & Motion

## 1. 职责与边界

把已核验的科学过程和已批准分镜转化为清晰、可执行的动画。动画必须帮助观众理解“什么在动、为什么动、先后关系是什么”，不能只追求复杂和炫技。

- 主 Skill 负责科学核验、旁白和分镜批准。
- 场景 Skill 负责空间与对象布局。
- 镜头 Skill 负责摄影机和镜头运动。
- 本 Skill 负责主体动作、机构运动、物理过程可视化、人物动作、时间节奏和动画执行。
- 灯光材质 Skill 负责表面和照明；动画不擅自改变材质外观。
- 不得凭空添加未经核实的内部机构、旋转方向、气流路径、温度变化或因果关系。

## 2. 动画设计的基本原则

1. 每个镜头只保留一个主要动作目标；复杂过程拆成可读阶段。
2. 先写动作逻辑，再决定关键帧、约束或模拟器。
3. 明确对象、动作、方向、起止状态、持续时间和停止条件。
4. 关键科学信息要有足够停留时间，不要让动作快到观众看不懂。
5. 动作必须符合物体连接关系、重力、惯性、碰撞和约束；艺术化慢动作应明确是视觉演示。
6. 不把摄影机运动与主体运动混为一谈，分别描述。
7. 任何单个镜头时长必须大于 0 秒且不超过 15 秒。跨越更长时间的动作必须拆镜头，或在明确说明的情况下用时间压缩/时间跳跃表达。
8. 角色动作、产品运动和物理可视化要与中文旁白/对白节奏对齐。
9. 模拟结果需要检查；不得声称未运行的模拟“物理准确”。

## 3. 动画规划工作流

### Step 1 — 还原真实过程
从已核验事实中提取：
- 初始状态
- 触发条件
- 参与对象
- 运动/变化的方向
- 作用关系与约束
- 中间状态
- 结束状态
- 可观测结果
- 不确定或不同型号可能不同的部分

缺少事实依据时先标记待核实，不能用动画想象补齐。

### Step 2 — 建立动作分层
按需要拆成：
- 主体动作：产品开关、旋转、移动、形变（真实存在时）。
- 部件动作：风扇、电机、齿轮、阀门、按钮等。
- 物理过程：气流、热量、水流、电流、振动等可视化。
- 人物动作：拿取、操作、观察、交流、反应。
- 环境动作：布料、头发、蒸汽、光线等，必须有合理原因。
- 摄影机动作：由镜头 Skill 独立规划。

### Step 3 — 写动作时间线
对每个镜头使用时间轴：
- 起始状态：对象位置、朝向、速度、开关状态。
- 触发/准备：动作如何开始。
- 主要动作：方向、速度变化、幅度、路径。
- 关键揭示：观众需要看清的瞬间或状态。
- 结束状态：对象停在哪里、朝向如何、是否继续运动。
- 停留：给旁白、字幕和观众理解留出时间。

时间轴必须落在镜头时长内，不可超出镜头结尾。动作阶段可用秒数或帧数描述，并标明帧率。

### Step 4 — 选择实现方式
- **关键帧动画**：可控、可重复的产品运动、按钮、机械部件和镜头辅助动作。
- **父子层级/约束**：轴向旋转、连杆关系、跟随、路径约束、限制运动范围。
- **Shape Keys**：真实存在的柔性变化、表情或可控形变；不能拿来伪造结构变化。
- **物理模拟**：布料、刚体、流体、烟雾等适合模拟且值得投入的内容。
- **程序化动画**：重复旋转、规律运动、粒子和可参数化效果。
- **手工动画/参考动作**：人物表演和精细交互。
- **AI 视频**：非关键几何的生活动作、人物反应和氛围镜头；精确机构与科学因果不应完全交给模型自由生成。
- **混合方案**：准确的 Blender 主体/机构动画 + 后期图形/AI 环境。

不要为简单动作引入昂贵模拟。选择最容易验证、最稳定的方式。

## 4. 科学过程可视化规则

### 气流/水流/热量/电流
- 先核验路径、方向、产生条件和边界。
- 使用线条、粒子、颜色或体积效果时，明确它们是解释性可视化，不是肉眼可见实体。
- 颜色含义必须前后一致并有中文图例；不要仅凭红色就暗示“温度更高”，除非数据支持。
- 粒子密度、速度和运动方向不可暗示未经证实的流量或强度。
- 不要让气流穿过实体、穿透错误部件或在没有来源时凭空出现。
- 如果真实过程无法精确模拟，采用简化示意并明确标注，不伪装成数值模拟。

### 机械结构
- 只动画已核实的部件。
- 旋转轴、连接点、转速关系、运动范围和碰撞关系必须有依据。
- 不要让固定部件漂浮、穿插或改变数量。
- 爆炸图与装配动画需要定义部件路径和最终装配状态；视觉分离不等于真实运行状态。

### 人物与产品交互
- 明确手部接触点、抓握方式、动作目标和视线。
- 道具与手之间不能穿模、瞬移或无故改变大小。
- 人物动作自然且节制；次要人物的表情/反应要服务于叙事。
- 若模型不能稳定同步口型，不强求角色说话镜头；可保留画面互动，用中文旁白讲解。

## 5. Blender 执行规范

每个动作写清：
- 对象名称与控制器
- 坐标系、局部/世界空间
- 起止帧与帧率
- 起止位置/旋转/缩放
- 关键帧插值和缓动
- 约束、父子关系和旋转轴
- 碰撞/模拟参数（若有）
- 缓存与烘焙要求
- 预览检查点和最终渲染要求

建议：
- 用 Empty/控制器驱动复杂对象，避免在多个部件上重复手动调整。
- 关键运动使用可读的 Action/NLA 命名。
- 模拟前先检查尺度、单位、碰撞体和时间步长。
- 需要稳定交付的模拟先缓存/烘焙，并记录依赖。
- 先做低采样 playblast/viewport preview，确认动作节奏和穿插，再最终渲染。
- 重要机构动作提供静态关键帧图，便于科学与视觉验收。

## 6. 输出格式

每个镜头输出：
1. 动作目的与观众应理解的信息
2. 科学依据/待核实项
3. 初始状态与结束状态
4. 对象动作清单及相互关系
5. 秒级/帧级动作时间线（总时长 ≤15 秒）
6. 实现方法（关键帧/约束/模拟/程序化/AI/混合）
7. Blender 对象、控制器、关键帧和缓存说明
8. 摄影机运动与主体运动的区分
9. 中文旁白/对白/字幕节奏对应
10. 连续性与验收清单

## 7. 中文语音与趣味表达

所有面向观众的旁白、对白和字幕默认使用简体中文/普通话。语气轻松、好奇、有画面感，带适度幽默；不要让动作拟人化造成错误科学结论。角色对白如有也必须中文，旁白仍是主叙事线。模型不能可靠生成汉字时留白，后期添加校对后的中文字幕。

## 8. 验收清单

- [ ] 动作符合已核验的科学过程
- [ ] 每个镜头时长 >0 且 ≤15 秒
- [ ] 动作时间线未超出镜头边界
- [ ] 起始状态、触发、关键动作和结束状态明确
- [ ] 部件连接、轴向、碰撞和约束正确
- [ ] 没有穿模、漂浮、瞬移或部件数量漂移
- [ ] 物理过程可视化有图例/示意标识且不误导
- [ ] 关键动作有足够停留时间
- [ ] 旁白/对白/字幕均为中文且与动作同步
- [ ] 已检查预览或实际模拟结果；未验证项已明确标记
