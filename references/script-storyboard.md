# 脚本与分镜设计指南

## 1. 脚本结构

建议默认 2.5–4 分钟，围绕一个核心问题展开。

| 段落 | 目标 | 内容 |
|---|---|---|
| 开场钩子 | 留住观众 | 一个熟悉现象、疑问或反常识 |
| 建立问题 | 让观众知道要解释什么 | 生活场景、使用体验 |
| 结构介绍 | 建立空间认知 | 外观、剖切、关键部件 |
| 原理拆解 | 完成知识传递 | 按因果顺序逐步展示机制 |
| 回到生活 | 让知识有用 | 使用边界、安全提醒或常见误区 |
| 总结收束 | 强化记忆 | 一句话总结、互动问题 |

## 2. 旁白原则

- 默认以第三人称旁白作为主叙事线。
- 人物可以在生活场景中出现、观察、操作和交流；除非用户明确要求，不需要让人物对白承担核心知识讲解。
- 每句话尽量只传递一个信息点。
- 抽象术语先用生活语言解释，再给出术语。
- 避免“神奇黑科技”“瞬间改变分子结构”等无依据表达。
- 旁白必须与画面对应，不能出现画面展示 A、旁白却讲 B 的情况。

## 4. 分镜字段

### 单镜头时长硬性限制

- **每个独立分镜最长 15 秒**，最短必须大于 0 秒。
- 超过 15 秒的连续内容必须拆成多个独立镜头，分别编号和填写时间码；不能把多个子镜头合并成一个长分镜来规避限制。
- 拆分依据应是信息点、动作阶段、景别/机位变化或视觉实现方式变化，保证每个镜头表达清楚且便于单独制作、生成和验收。
- 相邻镜头可以通过动作衔接、视线方向、气流方向、运动方向和声音连续性保持连贯。
- 全部分镜时间码必须连续、无重叠、无遗漏；所有镜头时长之和必须等于脚本总时长（允许因帧率产生不超过一帧的取整误差）。
- 输出前逐条校验时长，任何超过 15 秒的镜头都必须继续拆分。用户另行指定更短上限时，采用更严格的上限。

每个镜头必须说明：
- 镜头编号、起止时间码、时长（每镜头 ≤15 秒）
- 景别：远景/中景/近景/特写/微距
- 机位与运动：推、拉、摇、移、环绕、跟拍、固定
- 主体与动作
- 环境、材质、光线
- 关键结构或物理过程
- 旁白、字幕、音效
- 实现方式：实拍 / AI 视频 / Blender 3D / 动态图形 / 素材
- 连贯性要求与负面约束

## 5. 镜头设计原则

1. 先让观众知道物体是什么、处于什么环境，再进入内部结构。
2. 外观镜头建立真实感，剖切镜头建立空间认知，过程动画解释原理。
3. 关键机制应有完整连续镜头，不要只靠快速闪切。
4. 复杂过程拆成多个易懂步骤，避免同时出现过多箭头、粒子和标签。
5. 同一物体跨镜头保持形状、颜色、部件位置和比例一致。
6. 镜头运动服务于信息表达，不为炫技而旋转。
7. 字幕只突出关键词，不逐字堆满屏幕。

## 6. 提示词组成

建议结构：
主体 + 动作/过程 + 场景 + 镜头/构图 + 光线 + 材质 + 视觉风格 + 连贯性约束 + 负面约束。

不要只写“cinematic, 8K, masterpiece”。要具体说明镜头里发生什么、观众应该看懂什么。

## 7. 旁白与画面检查

逐句检查：
- 这句话是否有对应画面？
- 画面是否真的支持旁白结论？
- 需要标注“示意图”吗？
- 观众能否在当前镜头时间内读懂字幕？
- 是否把多个知识点塞进一个镜头？


## 8. 分镜系统 v2（本节覆盖旧版“一镜一提示词”的简单线性做法）

### 8.1 从叙事段到剪辑镜头
先拆知识点与视觉任务，再分镜。禁止直接按旁白字数平均切成 12–15 秒。每个镜头要回答“观众这一刻应该看懂什么”，不能只写“展示加热丝”“镜头围绕主体旋转”。

### 8.2 镜头组与视觉覆盖
同一知识段可由多个镜头构成，例如：
- 整体建立：交代设备/场景/部件所在位置。
- 结构总览：展示关键部件相互关系。
- 细节特写：只解释一个关键细节。
- 动作过程：展示状态变化或因果链。
- 结果/回归整体：解释局部如何影响系统整体。

按主题取舍，不要机械凑齐。连续镜头需有景别、角度、主体、动作或信息上的变化。相似镜头连续出现时必须说明叙事理由。

### 8.3 生成片段不是剪辑镜头
- 剪辑镜头是成片里的一个连续画面；生成片段是 AI/渲染工具输出的原始素材。
- 一个剪辑镜头通常对应一个生成片段。
- 如果需要硬切、多景别、不同空间或多个独立动作，拆成多个生成片段，后期剪辑；不要只在一个 15 秒 prompt 里写多个时间段并假设模型会准确切镜。
- 每个剪辑镜头和单次生成片段都必须 >0 且 ≤15 秒；记录素材时长与成片使用时长。
- 12–15 秒不是默认值。按动作、信息密度、生成模型能力决定时长。

### 8.4 运镜规则
- 默认优先固定机位或单一明确运动。
- 禁止无目的环绕主体。环绕只在需要揭示空间关系、展示多面结构且参考结构可靠时使用，并写明角度范围与揭示目标。
- 一个镜头最多一个主要运镜；避免同时推进、环绕、横移、升降等复杂组合。
- 明确起始构图、结束构图、摄影机运动还是主体运动、运动方向、速度、焦点和信息目的。
- 需要切换景别时拆镜，不用“先远景再特写再拉远”的多段提示词假装一个连续镜头。

### 8.5 镜头执行可行性
每镜标注 AI 执行等级：
- A：单一主体/动作/景别，简单固定或单一运镜，可单次生成。
- B：有阶段动作或较复杂结构，建议分片生成或首尾帧/多参考图（须确认工具支持）。
- C：精确几何、多部件协同、复杂运动或明确多景别剪辑，优先 Blender/精确 3D/后期合成。

### 8.6 分镜交付表
先交付叙事段落表，再交付剪辑镜头表，最后交付生成片段表。每个镜头必须有唯一视觉任务、旁白对应时间、景别、构图、主体动作、运镜目的、开始/结束状态、剪辑衔接、参考图和实现方式。详细模板见 `references/shot-design-v2.md`。
