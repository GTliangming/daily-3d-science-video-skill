# 选题定位与内容策略

## 1. 内容定位

核心方向：日常工具、家用电器和生活现象的写实 3D 原理拆解科普。让观众看见平时看不到的内部结构和过程，理解“它为什么这样工作”。

内容不应变成单纯产品测评，也不应只展示炫酷的内部动画。每期都要回答一个明确问题。

## 2. 受众与分享动机

面向普通家庭用户，兼顾家长、青少年和对生活原理好奇的人群。常见分享动机：
- 安全提醒：提醒家人正确使用，识别风险。
- 亲子解释：帮助家长给孩子讲清楚原理。
- 避免浪费/误用：减少错误操作，理解产品差异。
- 关心家人：解释父母常用设备或生活中的现象。

可将初期选题比例作为实验假设，而非固定规则：安全类约 40%，亲子解释约 30%，避坑类约 20%，关怀类约 10%。发布后根据数据调整。

## 3. 选题筛选

每个候选主题评估：
1. 普及度：普通家庭是否经常接触？
2. 好奇心：是否存在“原来如此”的认知落差？
3. 可视化：是否能通过剖切、爆炸图、流动、粒子或微观过程讲清楚？
4. 实用性：是否关联安全、使用、节能或消费决策？
5. 可验证性：是否能找到可信资料核实？
6. 制作成本：结构是否能在合理时间内建模和动画化？

优先选“高普及度 + 强可视化 + 可核验 + 一个核心问题”的主题。

## 4. 主题池

### 厨房与烹饪
电热水壶、微波炉、空气炸锅、电饭煲、电磁炉、榨汁机、冰箱。

### 浴室与个人护理
吹风机、电动牙刷、电动剃须刀、花洒、智能马桶。

### 家居环境
空调、电风扇、加湿器、吸尘器、扫地机器人、空气净化器。

### 电子设备
快充、充电宝、指纹锁、无线充电、蓝牙耳机、摄像头。

### 安全设备
插线板、烟雾报警器、漏电保护器、灭火器、燃气报警器。

### 日常物理现象
玻璃热冲击、吸盘、水滴形状、冰为什么漂浮、金属摸起来更凉、车窗起雾。

## 5. 角度设计示例

以吹风机为例：
- 原理向：吹风机如何把电能变成热风？
- 反常识：吹风机的热风为什么不一定会把头发烤焦？
- 结构向：电机、风道、加热组件和保护装置如何配合？
- 安全向：哪些使用方式可能导致进风口堵塞或过热？

注意：不同型号的电机位置、加热组件、温控和保护结构可能不同。不要把某一型号的结构当作所有吹风机的统一结构。

## 6. 视频长度与叙事节奏

建议默认 2.5–4 分钟，复杂主题可拆成系列，短平台版本可剪成 60–90 秒。建议节奏：
- 0–15 秒：提出反常识问题或生活困惑。
- 15–45 秒：呈现产品/现象和观众熟悉的体验。
- 45–90 秒：展示关键结构和系统关系。
- 90 秒–2.5 分钟：拆解核心原理，逐步解释因果链。
- 最后 30–40 秒：生活意义、安全边界和总结。
- 最后 10–20 秒：互动问题或下一期引导（按总时长调整）。

## 7. 选题通过标准

只有同时满足以下条件才建议进入制作：
- 核心问题一句话能说清。
- 有至少一个必须通过 3D 才更容易看懂的关键画面。
- 关键事实存在可核验路径。
- 不需要在一条视频里解释过多不同原理。
- 能提出一个对观众有用的结论或启发。
