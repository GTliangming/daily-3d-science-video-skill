# 科学事实核验规范

## 1. 总原则

AI 生成的解释只能作为研究线索，不能作为事实依据。任何会影响观众理解、产品安全或消费决策的结论，都必须核验。

## 2. 来源优先级

优先级从高到低：
1. 国家/行业标准、监管机构、政府或公共安全机构资料。
2. 产品制造商官方技术文档、说明书、维修资料和结构资料。
3. 专利、同行评审论文、大学或研究机构资料。
4. 权威科学传播机构、专业协会和可靠教材。
5. 有明确出处的专业媒体资料。
6. 普通网页、论坛和短视频仅作为线索，不单独支撑关键结论。

不同来源冲突时，记录冲突，不要擅自拼成一个“统一答案”。

## 3. 事实清单

每个主题至少核验：
- 设备/现象的定义与适用范围
- 关键部件及其功能
- 能量或物质转换路径
- 工作顺序与因果关系
- 关键数值、单位和测量条件
- 温度、压力、电压、功率等参数是否因型号/环境变化
- 安全保护机制及其适用边界
- 常见误解与不能推出的结论

## 4. 证据记录格式

| 字段 | 内容 |
|---|---|
| 待核验说法 | 脚本中准备表达的具体句子 |
| 结论状态 | 已核实 / 待核实 / 型号相关 / 推断 |
| 来源 | 标题、机构/作者、链接、日期 |
| 支持内容 | 来源实际支持了什么 |
| 适用范围 | 型号、条件、环境或样本限制 |
| 视频表达 | 可直接说、需要弱化、暂不使用 |

## 5. 表达边界

- 不把“通常”“可能”“部分型号”改写成“所有产品都”。
- 不把相关性描述成因果关系。
- 不把示意动画当成真实拍摄或真实比例。
- 不给出没有来源的精确数值。
- 不为了戏剧效果夸大危险或制造恐慌。
- 安全建议应尽量引用说明书、标准或权威机构。
- 结构未知时使用“典型结构示意”，并在画面或旁白中说明型号差异。

## 6. 可视化事实审核

对于 3D 镜头逐项检查：
- 部件数量、位置、形状和连接关系是否有依据？
- 运动方向和运动顺序是否正确？
- 热、气流、水流、电流、磁场等是否表达准确？
- 颜色只是视觉辅助，还是会让人误解物理机制？
- 剖切和爆炸视图是否清楚标明是示意？
- 动画是否暗示了现实中不存在的部件或过程？

## 7. 缺少资料时怎么办

1. 明确列出未知项。
2. 尝试寻找制造商说明书、专利或权威资料。
3. 若仍无法确认，改用不依赖该细节的讲法。
4. 将相关画面标注为概念示意，或删除该镜头。
5. 不得伪造来源、引用、参数或专家观点。
