## 验收

- [ ] 单镜头时长 ≤15 秒
- [ ] 叙事目的明确，主体清楚
- [ ] 起始和结束画面明确
- [ ] 运镜方向、路径和速度可执行
- [ ] 关键结构没有被遮挡或景深虚化
- [ ] 画面没有暗示未经核实的科学结论
- [ ] 与前后镜头的方向、尺度、外观和光线连续
- [ ] 旁白和人物对白均为自然普通话中文
- [ ] 语气轻松有趣，但科学表述准确
- [ ] 所有字幕、标题和可读画面文字均为正确简体中文
- [ ] 没有英文乱入、随机字母、伪文字或乱码
- [ ] 最终画幅下字幕/图形安全区足够
- [ ] 已检查预览、实际生成画面并试听音频
